# Changelog

All notable changes to this project are documented in this file. The format is
based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the
project follows [Semantic Versioning](https://semver.org/).

## [Unreleased]

### Added

- Open-source license, contribution guide, security policy, privacy notice, and
  community templates.
- Continuous integration, dependency update configuration, and tag-based
  Windows release automation.

## [1.1.3] - 2026-08-02

### Added

- Support for profile-style Story URLs such as `stories/username/`.
- Multi-video Story downloads with unique filenames and per-file metadata.
- Cleanup tests for cancellation during multi-Story downloads.

## [1.1.2] - 2026-07-19

### Added

- Initial public source release of the Electron/TypeScript Windows app.
- Reel and individual video Story downloads with quality selection.
- External Chrome/Edge login flow with persistent local sessions.
- Temporary cookie export, progress reporting, cancellation, and metadata TXT
  output.
